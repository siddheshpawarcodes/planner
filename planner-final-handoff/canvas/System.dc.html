Grounds

Neutral and slightly cool, so category colour carries all the meaning. There are no drop shadows inside the app: depth comes only from stepping bg → s1 → s2. Both themes get equal care; the default follows the system.

Categories: a transit map, not a rainbow

Seven lines, each a strong colour. Only the current and next task use the full colour; everything else is a quiet tint, 20% of the colour mixed into bg in dark and 16% in light. Fixed commitments are solid tinted bands. Completing a task promotes the next one to full colour. In the Week view a finished task saturates, so the week visibly fills in as you complete it.

Type

{{ t.k }}{{ t.spec }} {{ t.sample }}

Bricolage Grotesque for anything a person wrote or decided: task titles, screen titles, questions. It gives Planner its voice.

Geist for the interface and for big numerals (weight 300, tabular figures, tight tracking).

Geist Mono only for time: clock pills, ranges, durations. If it isn't a time, it isn't mono. Uppercase mono labels are rationed to state words (NOW, NEXT, MISSED, LISTENING).

Minimum sizes: 12px for any readable text, 9.5px only for single-word state labels. Everything scales with system text size up to 1.3×; the timeline grows its row height rather than truncating.
