# "Hey Planner" keyword models

Porcupine keyword files exported from the Picovoice Console for the phrase
**Hey Planner**, one per platform:

- `hey_planner_android.ppn`
- `hey_planner_ios.ppn`

They are git-ignored (they belong to your Picovoice account). Without them,
or without the AccessKey (see `config/secrets.example.json`), the wake phrase
stays off and tap-to-talk still works.
